# FourierLab 수학 노트

이 문서는 FourierLab이 실제로 계산하는 내용을 코드와 같은 기호로 정리합니다. 각 절 끝에 해당 구현 파일을 적어 두었습니다.

## 1. 좌표계

- **수학 좌표계**: y축이 위쪽입니다. 그리기 캔버스의 짧은 변이 [−1, 1] 구간에 대응하므로 길이 1은 그리기 캔버스 너비의 절반입니다. 모든 계산과 RMSE는 이 좌표계에서 합니다.
- **화면 좌표계**: Canvas의 CSS 픽셀 좌표이며 y축이 아래쪽입니다.

그리기 캔버스(너비 w, 높이 h, h_ = min(w, h)/2)는 다음 식으로 변환합니다.

```
x = (sx − w/2) / h_,     y = −(sy − h/2) / h_
```

시각화 캔버스는 중심 (cx, cy), 배율 zoom을 갖는 뷰를 사용합니다.

```
s  = zoom · min(w, h) / (2 · 1.15)
sx = w/2 + (x − cx) · s,     sy = h/2 − (y − cy) · s
```

y 부호는 화면에 그릴 때 한 번만 뒤집습니다. 그래서 수학 좌표계에서 반시계 방향인 회전(k > 0)은 화면에서도 반시계 방향으로 보입니다.
구현: `src/core/view.ts`

## 2. 곡선의 복소수 표현과 재표본화

사용자의 획 P = [(x₀, y₀), …]는 다음 순서로 처리합니다.

1. NaN·Infinity 좌표를 제거하고, 10⁻⁶보다 가까운 연속 점을 병합합니다(`cleanPath`).
2. 입력을 검사합니다. 비어 있거나, 서로 다른 점이 1개뿐이거나, 길이가 0.04 미만이거나, 좌표가 20 000개를 넘으면 오류 메시지를 반환합니다.
3. 경로 처리 방식에 따라 주기 경로를 만듭니다(3절 참고).
4. 누적 호 길이를 계산하고 **호 길이 기준 등간격**으로 N개 점을 만듭니다.
   - 닫힌 경로: s_j = j·L/N (j = 0..N−1). 마지막 점에서 시작점으로 돌아가는 구간도 L에 포함됩니다.
   - 열린 경로: s_j = j·L/(N−1). 첫 점과 마지막 점이 획의 양 끝점입니다.
5. 각 점을 복소수로 바꿉니다. z_n = x_n + i·y_n

샘플 수 N은 256, 512, 1024, 2048 중에서 고를 수 있고 기본값은 1024입니다. 원래 획(`stroke`)과 샘플(`samples`)은 따로 보존합니다. 중심 이동이나 정규화는 하지 **않습니다**. 원점은 그리기 캔버스의 중앙이며, 무게중심 이동은 DC 성분 c₀가 그대로 표현합니다.
구현: `src/math/path.ts`

## 3. 열린 곡선과 닫힌 곡선

푸리에 급수는 z(t + 1) = z(t)인 주기 함수를 표현합니다. 시작점과 끝점이 다른 획을 처리하는 방식은 세 가지입니다.

| 방식 | 주기 경로 | 결과 |
|---|---|---|
| 닫힌 경로 (기본) | 획 + 끝점→시작점 직선 | 연속 함수가 됩니다. 추가된 직선은 화면에 주황 점선으로 표시합니다. |
| 왕복 경로 | 획 + 역방향 획 | 연속 함수가 되고 새 선분이 없습니다. 대신 모든 부분을 두 번 지나갑니다. |
| 열린 경로 | 획 그대로 | 끝점→시작점이 **불연속(점프)**이 되어 깁스 진동이 생깁니다. 빨간 점선으로 표시합니다. |

불연속이 있는 신호의 계수는 대략 |c_k| ~ 1/|k|로, 꺾임만 있는 연속 신호의 계수는 ~ 1/k²로 줄어듭니다. 나선 예제로 확인해 보면 K = 100(저주파 순서)일 때 열린 경로의 오차가 닫힌 경로보다 큽니다(`fourier.test.ts`에서 검사).

여러 획을 한 번에 다루는 기능은 지원하지 않습니다. 새 획을 그리면 이전 획을 **대체**하고 그 사실을 안내 문구로 알려 줍니다. 이전 획은 실행 취소로 되돌릴 수 있습니다. 여러 획을 몰래 하나로 이어 붙이는 일은 하지 않습니다.

## 4. 이산 푸리에 변환

```
c_k = (1/N) Σ_{n=0}^{N−1} z_n · e^{−i2πkn/N}
```

- `fft.ts`의 `fft`는 기수-2 Cooley–Tukey 반복 구현입니다. 정규화하지 않은 순방향 변환 X_k를 계산하며, 회전 인자는 크기별로 캐시하고 각 각도를 직접 계산합니다(점화식을 쓰지 않으므로 오차가 누적되지 않습니다).
- `dft`는 O(N²) 참조 구현으로, `k·n mod N`을 먼저 줄인 뒤 각도를 계산합니다.
- 계수는 `c_k = X_k / N`입니다(`fourier.ts`).

**부호 있는 주파수**: 빈 index는 numpy `fftfreq`와 같은 규칙으로 바꿉니다. index < ⌈N/2⌉이면 k = index, 그 밖에는 k = index − N입니다. 짝수 N의 나이퀴스트 빈 N/2는 **k = −N/2**로 정의합니다. 표본 시점 t = n/N에서는 ±N/2를 구별할 수 없고, 표본 사이에서 그 원 하나의 회전 방향만 달라집니다.

곡선은 일반적인 복소 신호이므로 c_{−k} = conj(c_k) 같은 켤레 대칭을 **가정하지 않습니다**(테스트 "does not assume conjugate symmetry").

각 계수는 `{ k, re, im, amplitude = |c_k|, phase = atan2(im, re) }` 형태로 저장합니다.

## 5. 에피사이클과 재구성

```
ẑ(t) = Σ_{k∈S} c_k · e^{i2πkt},   0 ≤ t < 1
```

- 원의 반지름은 |c_k|입니다.
- 시각 t에서의 각도는 2πkt + arg c_k입니다. k > 0이면 반시계, k < 0이면 시계 방향으로 돌며, 한 주기 동안 |k|바퀴 돕니다.
- **연결 방식**: 원점(0) → c₀(고정된 DC 팔, 점선) → 선택된 성분을 화면 연결 순서대로 머리와 꼬리가 이어지게 합니다. 마지막 관절이 펜 끝 ẑ(t)입니다.
- 각도는 `k·t`의 소수부로 계산하므로 t = 0과 t = 1에서 비트 단위까지 같은 값이 나옵니다.

**원 개수 K**는 회전하는 성분(k ≠ 0)의 수입니다. c₀는 항상 포함하고 개수에 넣지 않습니다. 따라서 K의 범위는 1 ~ N−1입니다.

**성분 선택(어떤 K개)과 연결 순서(화면에서 쌓는 순서)는 별개입니다.**

| 선택 방식 | 순서 |
|---|---|
| 저주파부터 | +1, −1, +2, −2, … (같은 |k|이면 + 먼저) |
| 진폭 큰 순서 | |c_k| 내림차순(같으면 저주파 순서) |

연결 순서는 큰 원부터 또는 저주파부터 중에서 고를 수 있습니다. 합은 순서와 무관하므로 그려지는 곡선은 같습니다(테스트로 확인).

**궤적과 미리보기 곡선**: 선택된 계수를 길이 M = max(2N, 2048)인 배열의 빈 `k mod M`에 넣고 역 FFT를 하면, ẑ(m/M)을 O(M log M)에 정확히 계산할 수 있습니다(`evaluateSeries`). 궤적은 매 프레임 이 배열의 0 ~ ⌊tM⌋ 구간과 정확한 펜 끝으로 그립니다. 이전 프레임에 의존하지 않으므로 타임라인을 앞뒤로 임의 이동해도 결과가 정확합니다.

## 6. 근사 오차

같은 매개변수 위치(t = n/N)에서 원본 샘플과 재구성을 비교합니다.

```
RMSE = sqrt( (1/N) Σ_n |z_n − ẑ(n/N)|² )
```

정규화된 DFT의 파세발 정리를 쓰면 다음과 같습니다.

```
RMSE(S)² = Σ_{k∉S} |c_k|²
```

따라서 다음이 성립합니다.
- K를 늘릴 때 오차는 **절대 커지지 않습니다**. 선택 집합이 단조롭게 커지기 때문입니다.
- 진폭 순서 선택은 같은 K에서 RMSE가 **최소**입니다.
- K = N−1(전체)이면 RMSE = 0이며, 수치적으로는 반올림 오차 수준입니다.

오차 그래프 전체를 O(N)에 계산할 수 있습니다(`errorCurve`). 테스트에서는 이 값이 재구성 샘플로 직접 계산한 RMSE와 소수점 11자리까지 일치함을 확인합니다.

**단위**: 수학 좌표계 길이(그리기 캔버스 반폭 = 1)입니다. 화면 크기나 확대 배율과는 무관합니다. 상대 오차는 RMSE를 RMS 반지름 sqrt(Σ_{k≠0}|c_k|²)으로 나눈 값입니다.

### 관찰할 만한 현상 (실측)

- **원**: 진폭 순서 K = 1에서 상대 오차 0.0011%입니다. 예제가 360각형이라 남는 잔차입니다.
- **하트**를 **저주파 순서 K = 1**로 근사하면 오차가 약 100%입니다. 하트는 시계 방향으로 그려지므로 주된 성분이 k = −1인데, 저주파 순서는 +1을 먼저 고르기 때문입니다. 진폭 순서에서는 23%입니다.
- **별**은 5회 대칭이라 k ≡ 1 (mod 5) 성분만 0이 아닙니다. 그래서 저주파 순서 오차 곡선에 계단 모양이 나타나고, 진폭 순서는 K = 10에서 이미 0.62%입니다.

수치는 `npm run bench`로 다시 얻을 수 있습니다([PERFORMANCE.md](PERFORMANCE.md) 참고).
